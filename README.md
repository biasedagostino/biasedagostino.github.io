# Biase D'Agostino - Portfolio

Sito personale di Biase D'Agostino, Project & Product Management e Solution Analysis.

Il sito è una pagina statica (un solo file `index.html`) pubblicata con GitHub Pages.

## Cosa trovi

- **Chi sono**: una presentazione breve e i numeri essenziali del mio percorso.
- **Percorso**: le aziende in cui ho lavorato, con ruoli, date e clienti finali, dal 2007 a oggi.
- **Progetti scelti**: alcuni progetti, con il ruolo svolto in ciascuno.
- **AI**: come uso l'intelligenza artificiale nel lavoro.
- **Contenuti**: alcuni dei post che ho scritto su LinkedIn.
- **Contatti**: email, LinkedIn e CV.

## Contenuto del repository

- `index.html` - la pagina del portfolio
- `CV_BiaseDAgostino.pdf` - il CV, collegato dal sito
- `README.md` - questo file

## Pubblicazione

Il sito è servito da GitHub Pages. Per aggiornarlo basta modificare `index.html` e fare commit: la pagina si aggiorna da sola in pochi minuti.

## Contatti

Per scrivermi usa i pulsanti "Scrivimi" e LinkedIn sulla pagina.
